# Telegram Clicker Bot + Mini App 🪙

Телеграм бот-кликер с красивым Mini App интерфейсом! Нажимай на монету, зарабатывай, улучшай способности!

## 🎮 Возможности

### Mini App (Веб-интерфейс)
- 🎨 **Красивый дизайн** - градиенты, анимации, эффекты стекла
- 👆 **Кликер с анимацией** - парящая монета с эффектами
- ⚡ **Система энергии** - автовосстановление 1 в секунду
- 📊 **Статистика в реальном времени**
- ⬆️ **Улучшения** - увеличивай доход и энергию
- 🏆 **Таблица лидеров**
- 📳 **Haptic Feedback** - вибрация при кликах
- 💾 **Автосохранение** - прогресс сохраняется на сервер

### Telegram Bot
- 👆 Базовый кликер в чате
- 📊 Профиль с статистикой
- 🏆 Топ игроков
- ⬆️ Улучшения через бота
- 🎮 Кнопка запуска Mini App

## 📦 Установка

1. Установи зависимости:
```bash
npm install
```

2. Настрой `.env` файл (уже создан):
```
BOT_TOKEN=твой_токен
MINI_APP_URL=http://localhost:3000
PORT=3000
```

## 🚀 Запуск

### Запустить бота и сервер отдельно:
```bash
npm run bot      # Запустить только бота
npm run server   # Запустить только веб-сервер
```

### Запустить всё вместе (для разработки):
```bash
npm run dev      # Запустить бота + сервер с автоперезагрузкой
```

## 🔧 Настройка Mini App в BotFather

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь команду `/mybots`
3. Выбери своего бота
4. Нажми **Bot Settings** → **Menu Button**
5. Нажми **Edit Menu Button URL**
6. Введи URL: `http://localhost:3000` (для теста) или твой публичный URL

**Для публикации в интернет:**
- Разверни на Heroku, Vercel, Railway или другом хостинге
- Обнови `MINI_APP_URL` в `.env` на публичный URL
- Обнови URL в BotFather

## 🎨 Особенности Mini App

- **Адаптивный дизайн** - работает на всех устройствах
- **Плавные анимации** - парящая монета, летящие монетки
- **Glassmorphism** - современный эффект стекла
- **Тактильная отдача** - вибрация при действиях
- **Оптимизация** - debounced сохранение, минимум запросов

## 🛠️ Технологии

- **Backend**: Node.js, Express
- **Bot**: node-telegram-bot-api
- **Frontend**: Vanilla JS, CSS3 animations
- **Database**: JSON file storage
- **API**: RESTful endpoints

## 📱 API Endpoints

- `GET /api/user/:userId` - Получить данные пользователя
- `POST /api/user/:userId` - Сохранить данные
- `GET /api/leaderboard` - Топ 10 игроков
- `POST /api/upgrade/income/:userId` - Улучшить доход
- `POST /api/upgrade/energy/:userId` - Улучшить энергию

## 🐛 Устранение проблем

**Mini App не открывается:**
- Убедись, что сервер запущен (`npm run server`)
- Проверь, что URL в BotFather правильный
- Для локального теста используй ngrok или localtunnel

**Прогресс не сохраняется:**
- Проверь, что сервер запущен
- Открой консоль браузера (в Telegram: Settings → Advanced → Debug)

## 📝 Заметки

- Для локального теста используй ngrok: `ngrok http 3000`
- Для продакшена используй HTTPS (обязательно для Mini Apps)
- База данных - простой JSON файл, для больших нагрузок используй PostgreSQL/MongoDB
